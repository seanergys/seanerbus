# Various bit and bobs

## `cmake_config_build_test`

C++ SeanerBUS example that uses `find_package(Seanerbus)` to find the Seanerbus.

Can be used to test the CMake Config scripts.

## `pkgconfig_build_test`

C++ SeanerBUS example that uses pkg-config to find the SeanerBUS.

Can be used to thest the generated pkg-config files.

## `scenario_tests`

An end-to-end test scenario of a Python publisher and a C++ subscriber.
